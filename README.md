# 🛒 Shopping List App (SwiftUI)

Aplicativo iOS desenvolvido em **SwiftUI** para gerenciar listas de compras de forma simples e prática.

O usuário pode adicionar, remover e marcar itens como concluídos, facilitando o controle dos produtos durante as compras.

---

## 🚀 Funcionalidades

- ➕ Adicionar novos itens
- 🗑️ Remover itens da lista
- ✅ Marcar itens como comprados
- 🔄 Atualização automática da interface
- 📱 Interface simples e intuitiva

---

## 🧠 Como funciona

Cada item da lista possui dois estados:

- **Pendente** → item ainda não comprado  
- **Concluído** → item já comprado  

A interface é atualizada automaticamente através do gerenciamento de estado do SwiftUI.
